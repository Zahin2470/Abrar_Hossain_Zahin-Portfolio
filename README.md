## ✦ About This Portfolio

A **premium, production-grade personal portfolio** built from scratch with Next.js 14, Tailwind CSS, and Framer Motion. Goes far beyond a standard portfolio — featuring a **live star canvas with spider-web cursor**, **dark/light mode with day sky and sun**, **lightning bolts**, **live GitHub stats dashboard**, **Kaggle live badge**, **interactive skill radar chart**, **4 free AI-powered tools** (chatbot, paper summarizer, research idea generator, resume builder), and much more.

> *"Turning data into intelligence, one model at a time."*

## ✦ Visual Effects & UI

| Effect | Description |
|---|---|
| ⭐ **Gold Star Canvas** | Hundreds of twinkling gold stars that drift smoothly across the screen |
| 🕸️ **Spider-Web Cursor** | Gold cursor dot + lagging ring; moving the cursor draws golden web lines to nearby stars |

| 🎯 **Custom Gold Cursor** | Gold dot + lagging amber ring — both react to hover on interactive elements |
| 🎬 **Scroll Reveal** | Elements animate in as you scroll using intersection observer |
| 🔢 **Live Visitor Counter** | Animated visit count badge in the navbar powered by countapi |
| 📱 **Fully Responsive** | Optimised for mobile, tablet, and desktop |

## ✦ AI-Powered Tools (All Free · No Account Needed)

All tools run on **Groq API (free tier)** with **Llama 3.3 70B** — no credit card, no signup required.

### 🤖 AI Chatbot (`/chat`)
Knows everything about Zahin — research papers, projects, skills, background. Visitors can ask anything and get instant, accurate answers.

### 📄 Paper Summarizer (`/paper-summarizer`)
Paste any research paper abstract or title. Returns:
- **TL;DR** — one casual sentence
- **The Problem** — what gap it addresses
- **The Method** — specific techniques used
- **Key Findings** — results and numbers
- **Why It Matters** — real-world impact
- **Key Terms** — jargon decoded in plain English

### 💡 Research Idea Generator (`/research-ideas`)
Choose from **12 preset topic chips** (Medical Imaging, Cybersecurity, Green AI, NLP, Federated Learning…) or type your own. Get 5 novel research directions each with:
- Specific title and punchy tagline
- Problem statement, methodology, novelty, expected outcome
- Difficulty level (MSc / PhD / Industry), time estimate, keywords

### 📋 Resume Builder (`/resume-builder`)
- **3 templates** — Sidebar, Classic, Minimal
- **5 colour themes** — Violet, Slate, Emerald, Rose, Indigo
- **Live preview** — updates as you type
- **PDF export** — one click, proper A4 formatting with colour printing
- **Sample data** — pre-fills with Zahin's real info as a reference

## ✦ Quick Start

### 1 · Create project & install

```bash
npx create-next-app@14 zahin-portfolio
cd zahin-portfolio
npm install framer-motion
```

### 2 · Copy all files

Replace the generated `src/` folder with the files from this repo.

### 3 · Add your photo and resume

```
public/
├── images/profile/developer-pic-1.png    ← your profile photo
└── resume.pdf                            ← your CV
```

### 4 · Run dev server

```bash
npm run dev
# Open http://localhost:3000
```
